# PGLife - Paying Guest Accommodation Finder

PGLife is a full-stack web application designed to help users search, filter, and view paying guest (PG) accommodations across major cities. It provides a simple, interactive interface for users to discover housing options and view detailed property information.

### Key Features

* **City-Based Search:** Browse PG listings in major metropolitan cities (Delhi, Mumbai, Bengaluru, Hyderabad).
* **User Authentication:** Sign up and login modal functionality for user accounts.
* **Property Listings:** View detailed information, amenities, and pricing for available properties.
* **Responsive Design:** Clean, modern user interface optimized for different screen sizes using HTML, CSS, and Bootstrap.

### Tech Stack

* **Frontend:** HTML5, CSS3, Bootstrap, JavaScript
* **Backend:** PHP
* **Database:** MySQL
